# Phase 08: 실제 장치 직접 할당과 DMA 격리

- 상태: 환경 미확보
- 목적: USB 카메라와 NVIDIA GPU를 각 pVM에 배타적으로 할당하고, 장치 DMA가 소유 pVM 밖으로 나가지 못하게 한다.
- 환경: E-3
- 관련 목표: G-8, G-9
- 관련 결정: D-7, D-9

## 선행 조건

- E-3 하드웨어 확정 (D-9). S2MPU와 assignable device를 제공하는 arm64 시스템이 필요하다.
- USB 카메라 1대와 NVIDIA GPU 1대
- Phase 02의 pKVM 커널이 해당 하드웨어에서 부팅
- Phase 05의 다중 pVM 운용 성공

E-3는 arm64와 NVIDIA GPU를 동시에 만족해야 한다. 이 조합의 확보가 Phase 전체의 최대
선행 리스크다.

## 계획

1. E-3 하드웨어에서 pKVM 커널을 protected 모드로 부팅한다.
2. `Found N assignable devices` 로그로 할당 가능 장치를 확인한다. Phase 03의 E-1에서는
   이 값이 0이었다.
3. USB 카메라를 Camera pVM에, NVIDIA GPU를 AI pVM에 배타적으로 할당한다.
4. Host와 다른 pVM에서 해당 장치에 접근할 수 없음을 확인한다.
5. 장치 DMA가 소유 pVM의 메모리 범위를 벗어나지 못하는지 S2MPU 설정으로 확인한다.
6. 범위를 벗어나는 DMA를 의도적으로 유발해 차단 결과를 대조군으로 남긴다.
7. pVM 종료 후 장치 소유권이 회수되고 재할당 가능한지 확인한다.

## 완료 조건

- 두 장치가 각각 다른 pVM에 할당된 로그가 있어야 한다.
- 할당 중 Host와 비소유 pVM의 접근이 차단되어야 한다.
- 소유 pVM 범위를 벗어난 DMA가 S2MPU에서 차단되어야 한다.
- pVM 종료 후 장치가 회수되고 다시 할당되어야 한다.
- 차단 결과에는 반드시 대조군(차단되지 않는 정상 접근)이 함께 있어야 한다.

## 한계

이 Phase가 완료되기 전까지 "Host가 침해되어도 모든 경로에서 pVM 메모리가 보호된다"는
주장을 하지 않는다. Phase 04의 결과는 CPU 매핑 경로에 한정된다.

장치 할당 성공은 pVM 내부에서 해당 장치 드라이버가 정상 동작한다는 뜻이 아니다. GPU
드라이버 기동은 Phase 10의 선행 확인 항목으로 별도로 다룬다.
