# Phase 07: 동적 pVM 수명주기 관리

- 상태: 방식 미결
- 목적: Host 요청으로 pVM을 생성하고 종료하는 제어 흐름을 권한 검사와 이미지 검증까지 포함해 성립시킨다.
- 환경: E-1
- 관련 목표: G-7, 부분적으로 G-5
- 관련 결정: D-4, D-6

## 선행 조건

- Phase 05의 pVM 2개 동시 운용 성공
- Host Application과 pVM 관리 경로 사이의 제어 인터페이스 정의
- pVM 이미지 검증 방식 결정 (D-6)

## 계획

1. Host Application의 pVM 생성/종료 요청을 받는 제어 경로를 정의한다.
2. 요청자의 권한과 정책을 확인하는 최소 검사를 구현한다. 거부 경로를 먼저 만든다.
3. pVM 이미지의 무결성 검증 방식을 결정한다. pvmfw 기준을 먼저 평가하고, upstream pKVM에
   pvmfw 항목이 없으므로 대체 경로를 함께 검토한다.
4. 생성, 실행 상태 모니터링, 종료를 하나의 제어 흐름으로 묶는다.
5. 한 pVM의 장애가 다른 pVM과 Host 제어 경로로 전파되지 않게 격리한다.
6. 종료 후 메모리와 vCPU 자원 회수를 확인한다.

## 완료 조건

다음 다섯 경로가 각각 재현되고 로그로 구분되어야 한다.

| 경로 | 판정 |
|---|---|
| 권한 거부 | 권한 없는 요청에서 pVM이 생성되지 않는다 |
| 이미지 검증 실패 | 변조된 이미지에서 생성이 중단된다 |
| 정상 생성 | 검증을 통과한 이미지로 pVM이 실행 상태에 도달한다 |
| 장애 격리 | 한 pVM의 비정상 종료가 다른 pVM과 제어 경로에 전파되지 않는다 |
| 정상 종료 | 종료 요청 후 메모리와 vCPU가 회수된다 |
