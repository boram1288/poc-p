# Phase 10: AI 추론 파이프라인 통합

- 상태: 미착수
- 목적: AI pVM이 전달받은 프레임으로 추론을 수행하고 허용된 결과만 Host Application에 반환한다.
- 환경: E-3
- 관련 목표: G-11
- 관련 결정: D-9

## 선행 조건

- Phase 08의 추론 역할 장치 할당 성공과 pVM 내부 드라이버 기동 확인
- Phase 09의 프레임 전달 경로 성립
- AI pVM에 넣을 최소 추론 모델과 판정 가능한 입력 프레임

D-9 확정으로 이 Phase는 QEMU 환경에서 수행한다. GPU 가속은 사용하지 않는다. AI pVM 안의
추론은 CPU 경로로 수행하며, 판정 대상은 데이터 보호 경계와 파이프라인 성립이다.

## 계획

1. AI pVM 안에서 추론 런타임을 기동한다. GPU 가속 없이 CPU 경로로 수행한다.
2. Phase 09로 전달받은 프레임에 대해 추론을 수행한다.
3. 모델 가중치와 중간 데이터가 AI pVM 밖으로 나가지 않음을 확인한다.
4. 추론 결과만 Host Application으로 반환하는 경로를 구현한다. 반환 대상 필드를 명시적으로
   허용 목록으로 관리한다.
5. 캡처, 전달, 추론, 결과 반환을 반복 실행하고 Host Application의 종료 명령으로 정지한다.
6. 파이프라인 종료 후 두 pVM의 장치와 메모리 자원을 회수한다.

## 완료 조건

| 검사 | 판정 |
|---|---|
| 추론 수행 | AI pVM이 전달받은 프레임에 대해 CPU 경로로 추론을 완료한다 |
| 결과 반환 | Host Application이 추론 결과를 수신한다 |
| 영상 비노출 | 영상 원본에 대한 Host 접근이 차단된다 |
| 모델 비노출 | 모델 가중치와 중간 데이터에 대한 Host 접근이 차단된다 |
| 반복 실행 | 캡처부터 결과 반환까지 반복되고 종료 명령으로 정지한다 |
| 자원 회수 | 종료 후 할당 장치, 메모리, vCPU가 회수된다 |

## 한계

추론 정확도, 처리량, 지연은 평가하지 않는다. 데이터가 정해진 경계를 넘지 않는지와
파이프라인이 반복 성립하는지만 판정한다.

단일 카메라, 단일 추론 장치, 단일 파이프라인 구성만 다룬다.

E-3는 에뮬레이션 환경이다. GPU 가속 추론과 실물 NVIDIA GPU에서의 데이터 보호는 이
Phase에서 검증하지 않으며 후속 과제로 남긴다. README 성공 조건 5는 Reference Scenario의
GPU 추론을 CPU 경로 추론으로 대체해 기술되어 있다.
